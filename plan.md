# Plan: Tropical un pezzo d'Italia home page (JS-rendered, Webpack)

## Overview
Build the home page in `design_handoff_home_page/` (desktop 1a, mobile 1b, spec 1c), with all page content generated by JS using `createElement` and `appendChild`. Work is split into the tasks below and tracked on the todo4vcode board. `CLAUDE.md` holds the workflow rules.

## Decisions
- **Scope:** home page only. Nav links go to the existing pages on tropicalunpezzo.se.
- **Images:** striped placeholders for the three photos, matching the design's exact sizes. The real logo is the SVG in the repo root, moved to `src/assets/logo.svg`.
- **Map:** a real Google Maps iframe, because the handoff specifies it and it needs no supplied asset.
- **Commits:** Claude proposes each commit, and the user commits and pushes.

## Architecture
`src/template.html` stays a bare shell: `<head>` plus `<div id="content"></div>`. HtmlWebpackPlugin requires it. Everything in the body is built in JS.

```
src/
  index.js              imports global CSS, appends sections to #content
  template.html
  data/content.js       single source for copy, hours, address, URLs
  utils/dom.js          createEl(tag, { className, text, attrs })
  components/           button, logo, imagePlaceholder, hoursTable
  sections/             header, mobileMenu, hero, hoursCard, intro, pasta,
                        twoWorlds, visit, footer, stickyBooking (each .js + .css)
  styles/               tokens.css, fonts.css, base.css
  assets/               logo.svg, fonts/*.woff2
```

Module pattern, used by every section:
```js
export function createIntro() {
  const section = createEl("section", { className: "intro" });
  section.appendChild(createEl("p", { className: "intro__lead", text: content.intro.lead }));
  return section;
}
```

**Responsive approach:** one DOM for all widths, adapted with CSS (grid, `order`, `display: none`). No separate mobile and desktop markup. Breakpoints: ≤767, 768–1023, ≥1024.

## Design gaps to confirm with the client (built as drawn until then)
- On mobile the design has no Öppettider section and no way to reopen a dismissed hours card, so hours are gone for that browser session.
- "välkommna" is a known typo on the live site. Kept verbatim until the client confirms the fix.
- No light logo was supplied, so the footer uses `logo.svg` on the dark background. It may need a light version.
